# Data

The HTE datasets are not vendored. Fetch them from the EDBO repository (Shields et al., Nature 2021) into `data/raw/`:

```bash
for d in aryl_amination suzuki direct_arylation; do
  curl -sS -o data/raw/edbo_${d}_experiment_index.csv \
    https://raw.githubusercontent.com/b-shields/edbo/master/experiments/data/$d/experiment_index.csv
done
```

`hte/data.py` checks the SHA-256 prefix of each file (aryl_amination 88e47ff4ebcd1dac, suzuki cc1abd59e4f5f8f8).
Original sources: Ahneman et al., Science 2018 (Buchwald-Hartwig); Perera et al., Science 2018 (Suzuki-Miyaura).

`fold/C.npy` (contact matrix) is regenerated by `python3 -I fold/build.py`.
Request journals (every API request and response) are kept outside the repository.
