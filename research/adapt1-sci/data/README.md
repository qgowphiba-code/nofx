# Data

The HTE datasets are not vendored. Fetch them from the EDBO repository (Shields et al., Nature 2021) into `data/raw/`:

```bash
for d in aryl_amination suzuki direct_arylation; do
  curl -sS -o data/raw/edbo_${d}_experiment_index.csv \
    https://raw.githubusercontent.com/b-shields/edbo/master/experiments/data/$d/experiment_index.csv
done
```

`hte/data.py` checks the SHA-256 prefix of each file (aryl_amination 88e47ff4ebcd1dac, suzuki cc1abd59e4f5f8f8).
Original sources: Ahneman et al., Science 2018 (Buchwald-Hartwig); Perera et al., Science 2018 (Suzuki-Miyaura).

`fold/C.npy` (contact matrix) is regenerated by `python3 -I fold/build.py`.
Request journals (every API request and response) are kept outside the repository.

Additional raw data used by later rounds (fetch into data/raw/):
- simglucose (UVA/Padova virtual patients): https://raw.githubusercontent.com/jxx123/simglucose/master/simglucose/params/{vpatient_params.csv,Quest.csv}
  (model equations re-implemented in varied/uvap.py from simglucose/patient/t1dpatient.py)
- Sachs 2005 pooled data and consensus network: https://raw.githubusercontent.com/FenTechSolutions/CausalDiscoveryToolbox/master/cdt/data/resources/{cyto_full_data.csv,cyto_full_target.csv}
- GB1 four-site landscape (Wu et al. 2016), FLIP copy: https://raw.githubusercontent.com/J-SNACKKB/FLIP/main/splits/gb1/four_mutations_full_data.csv.zip (unzip into data/raw/gb1/unz/)
